## Если вы знаете Python

Типовые конфигурации очень похожи на готовые пакеты, которые вы ставите через `pip`:

| Python | 1С |
| --- | --- |
| Готовый пакет, например Django, вместо своего веб-фреймворка | Типовая конфигурация вместо своей программы с нуля |
| `pip install --upgrade django` | Установить обновление типовой |
| Поправить код прямо в папке `site-packages` | Изменить код внутри самой типовой |
| Свой модуль, который наследует классы пакета и меняет их поведение | Расширение конфигурации |

Если поправить код прямо в `site-packages`, после следующего `pip install --upgrade` ваши правки молча пропадут. Опытный Python-разработчик так не делает: он пишет свой код поверх пакета.

В 1С правки внутри типовой не пропадают молча, но при каждом обновлении их приходится вручную сводить с новой версией. Это и случилось с Вовой. Поэтому правило такое же: свои изменения держим отдельно, в расширении.
