## Где лежит информационная база

Самый простой вариант, с которого начинают все: база — это **обычная папка на диске**. Внутри неё главный файл с именем `1Cv8.1CD`. В этом одном файле хранится всё: и конфигурация, и данные фирмы.

  ]}
/>

Такой вариант называется **файловым**. Он хорош для обучения, маленьких фирм и одного-двух пользователей. Наша учебная база тоже будет файловой.

Когда у фирмы десятки или сотни пользователей, базу хранят иначе: на отдельном сервере, внутри профессиональной базы данных, например PostgreSQL или Microsoft SQL Server. Это называется **клиент-серверный** вариант.

Для программиста разницы почти нет: конфигурацию он пишет одинаково для обоих вариантов. Подробно сравним их в уроке 6 этой темы, а пока достаточно запомнить, что база бывает файловой и серверной.

<Callout variant="important">
Не копируйте и не переносите папку с базой, пока с ней кто-то работает: файл может сохраниться наполовину. Для копий у 1С есть специальный безопасный способ, о нём поговорим через пару шагов.
</Callout>
