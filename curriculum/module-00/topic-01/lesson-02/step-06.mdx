## Всё это уже было в Python

Почти всё из этого урока у вас уже встречалось, только под другими названиями:

| Python | 1С |
| --- | --- |
| Интерпретатор Python, один на компьютере | Платформа, одна на компьютере |
| Файл `main.py`, который вы правите в редакторе | Основная конфигурация, черновик |
| Программа, которая уже запущена и работает | Конфигурация базы данных |
| Перезапустить программу, чтобы применить новый код | Обновить конфигурацию базы данных |
| Папка с исходниками без данных | Файл `.cf` |
| Исходники вместе с базой данных, упакованные в архив | Файл `.dt` |

Пример из жизни: вы запустили программу «Холодильник» и поменяли код в `main.py`. Пока программу не перезапустите, она продолжит работать по старому коду. В 1С всё так же, только «перезапуск» называется обновлением конфигурации базы данных. Именно на этом и попался Вова с полем «Любимый мастер».
