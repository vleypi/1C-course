## Итоги

<CheckList>
- Платформу устанавливают на компьютер один раз, и она работает с любым количеством баз.
- При запуске 1С открывается список информационных баз: выбираете нужную, как сохранение в игре.
- Файловая база — это папка с главным файлом `1Cv8.1CD`. Для больших фирм базу хранят на сервере.
- Внутри базы лежат конфигурация (правила) и данные (записи). Конфигурация определяет, какие данные можно хранить.
- Конфигураций в базе две: **основная** (черновик программиста) и **конфигурация базы данных** (рабочая версия). Изменения доходят до пользователей только после обновления.
- Копии: `.cf` — только конфигурация, `.dt` — вся база с данными.
</CheckList>

## Проверь себя

Сначала ответьте мысленно, потом раскройте ответ.

<SelfCheck>
  <Question title="На ноутбуке Артёма стоят три базы: рабочая, копия и учебная. Сколько платформ ему нужно установить?">
    Одну. Одна платформа умеет работать с любым количеством баз.
  </Question>
  <Question title="Программист добавил в карточку клиента поле «Любимый мастер», но администратор его не видит. Почему?">
    Программист изменил основную конфигурацию, то есть черновик, но ещё не обновил конфигурацию базы данных. Пока он этого не сделает, пользователи работают по старой рабочей версии.
  </Question>
  <Question title="Нужно отправить программу «Барбершоп» знакомому в другой город, чтобы он завёл в ней своих клиентов. Какой файл лучше отправить: .cf или .dt?">
    `.cf`: в нём только конфигурация, без клиентов «Бритвы». Знакомый загрузит её и начнёт вносить своих клиентов с нуля. Файл `.dt` отправил бы ещё и все данные Артёма, а это лишнее и небезопасно.
  </Question>
  <Question title="Почему нельзя просто скопировать папку с базой, пока администратор оформляет визит клиента?">
    Файл базы в этот момент может меняться, и копия сохранится наполовину. Безопасный способ — выгрузить базу в файл `.dt`.
  </Question>
</SelfCheck>

## Словарик

<Glossary>
  <GlossaryTerm term="Версия платформы">Номер выпуска платформы, например 8.3.24. Новые версии исправляют ошибки и добавляют возможности.</GlossaryTerm>
  <GlossaryTerm term="Список информационных баз">Окно, которое открывается при запуске 1С. В нём выбирают, с какой базой работать.</GlossaryTerm>
  <GlossaryTerm term="Файловая база">База в виде папки на диске с главным файлом 1Cv8.1CD.</GlossaryTerm>
  <GlossaryTerm term="Клиент-серверная база">База, которая хранится на сервере внутри профессиональной базы данных. Для фирм с большим числом пользователей.</GlossaryTerm>
  <GlossaryTerm term="Основная конфигурация">Черновик программиста внутри базы. Пользователи его не видят.</GlossaryTerm>
  <GlossaryTerm term="Конфигурация базы данных">Рабочая версия конфигурации, по которой работают пользователи.</GlossaryTerm>
  <GlossaryTerm term="Обновление конфигурации базы данных">Перенос изменений из черновика в рабочую версию.</GlossaryTerm>
  <GlossaryTerm term="Файл .cf">Конфигурация без данных, сохранённая в файл.</GlossaryTerm>
  <GlossaryTerm term="Файл .dt">Вся информационная база целиком, выгруженная в один файл: конфигурация и данные.</GlossaryTerm>
</Glossary>
