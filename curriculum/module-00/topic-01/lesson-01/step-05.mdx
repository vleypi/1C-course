## Одним глазком на код

Учить язык пока не будем, просто посмотрите, как он выглядит. Вот одно и то же приветствие клиента на двух языках:

```bsl title="Язык 1С"
Процедура ПоприветствоватьКлиента(ИмяКлиента)
    Сообщить("Добро пожаловать, " + ИмяКлиента + "!");
КонецПроцедуры

ПоприветствоватьКлиента("Иван");
```

```python title="Python"
def greet_client(client_name):
    print("Добро пожаловать, " + client_name + "!")


greet_client("Иван")
```

Что бросается в глаза:

- Код на 1С пишется **по-русски**: `Процедура` вместо `def`, `Сообщить` вместо `print`.
- Конец процедуры обозначают словом `КонецПроцедуры`, а не отступом, как в Python.
- Строки заканчиваются точкой с запятой `;`.

Логика при этом та же самая: объявили процедуру с параметром, потом вызвали её по имени. Знания из Python здесь пригодятся. Язык подробно разберём в уроке 8 этой темы и во втором модуле.
